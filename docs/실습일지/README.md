# 실습일지

심화응용프로젝트는 매주 실습일지(docx)를 제출한다. 원고는 `NN주차.md`(커밋 대상),
제출본은 `실습일지_NN주차.docx`(학번·이름이 들어가 git 제외). 빈 양식은 `양식.docx`(역시 git 제외).

`/실습일지 N주차`로 만든다. 인자가 없으면 아래 표에서 마감이 가장 가까운 미제출 일지를 고른다.

## 주의 — 일지 번호와 작업 주차는 한 칸 어긋난다

마감은 월요일 수업일이고, 실습일자는 **직전 마감 다음 날 ~ 이번 마감일**이다.
그래서 7주차 일지에는 6주차 작업이 주로 들어간다.
**일지 재료는 주차 번호가 아니라 아래 실습일자 날짜 범위로 고른다.**

## 양식

제목줄("2026 심화응용프로젝트 실습일지"), 학번·이름 줄, 5행 표.

| 행 | 담는 것 |
|---|---|
| 주제 | OnlyWhatMatters |
| 실습일자 | 위 표의 실습일자 |
| 실습내용 | 한 주간 수행한 내용을 간략하게 (불릿 3~6개) |
| 실습결과 | 실행결과 화면 캡처, 주요 소스코드, 바뀐 판단과 이유("기존 방식 → 문제 → 변경 이유") |
| 기타 | 향후 해야 할 사항 |

문체는 개조식("~ 구현", "~로 변경", "~함").
